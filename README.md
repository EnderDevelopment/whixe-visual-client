# Minecraft Visual HUD Mod

WHIXE CLIENT is a client-side Minecraft Fabric visual HUD mod for Minecraft 1.21.11. It adds configurable coordinates, FPS and keystrokes displays, a cinematic now-playing title, and a compact music panel, managed through an in-game GUI with clean and cinematic presets.

## Install

1. Install Java 21, Fabric Loader for Minecraft 1.21.11, and the matching Fabric API.
2. Build the mod with `./gradlew build`.
3. Put the generated `whixe-client` JAR from `build/libs` into your Minecraft `mods` folder.
4. Launch Minecraft with the Fabric profile.

## Use

1. Press `0` to open the WHIXE CLIENT menu. Change this key in Options > Controls > Key Binds > WHIXE CLIENT.
2. Use the Visuals tab to toggle the HUD and its coordinate, FPS, keystrokes, and cinematic elements.
3. Use the Music tab to show or hide the panel and toggle its local play/pause state. The track title is a local sample label; this mod does not connect to Spotify or control Spotify playback.
4. Use the Presets tab to apply the clean or cinematic visual setup. Settings are saved in `config/whixe.properties`.
